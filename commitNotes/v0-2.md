## 🔧 Büyük tasarım kararları / değişiklikler

1. **Kimlik tipi:** `organizationId` **string → int** her yerde. Dış referans **`organizationCode`** (string).
2. **Hiyerarşi netleşti:** **Organization → Solution → Service → {Property · ProcessViewProfile · ProcessStep · WorkRule}**;
   `ProcessStepAction → ProcessStep`. **Solution** ve **Service** ayrı model olarak eklendi.
3. **Organizasyon havuzu:** **Action · Status · Style · Translation** → `organizationId` (Service'e değil); tüm servislerde kullanılır.
4. **Translation kayıt-başına-dil:** `tr`/`en`/`de` kolonları kaldırıldı → **`languageCode` + `definition`**;
   benzersizlik `(organizationId, code, languageCode)`; çözümleme `code`+`languageCode`+`organizationId`.
5. **Style:** yalnız **Action + Status** tüketir; **form alanları Style varlığını kullanmaz**. Ref alanı **`style` → `styleId`** (FK).
   Status'ta `definition` metni + `icon` rengi Style'ın **`fontColor`**'ından gelir.
6. **Action → ProcessStepAction bağımsız kopya:** alanlar **bir kez kopyalanır**; **`actionId` FK yok** (Action değişince binding'ler etkilenmez).
7. **Processing** yeniden sınıflandı: bekleme noktası **değil** — frontende form döner ama **`default`** ile otomatik ilerler.
8. **Değer Atama:** `valueType`'a **`FromCalculation`** (+ `expression`) eklendi.
9. **Form List profil-bazlı override (B2):** **`ProcessViewProfilePropertySetting {viewProfilePropertyId, key, value}`**
   (propertyType'a göre dictionary). Form List ayarları Property'den taşındı:
   `addNewEnabled` → **`activeStartActions`** (ProcessStepAction id listesi) ·
   `addFromExistingRecordsIsActive` → **`addFromExistingStatusIds`** (Status id listesi) ·
   `selectedEnable` → **`selectableModeActive`** (Form List **alan-düzeyi**) · öneri `selectedEditable` (profil).
10. **DB anahtarları:** eksik PK/FK'ler eklendi; birincil anahtar adı **`id`** (property'de `propertyId`→`id`); view-profile'a `id`/`serviceId`.

## ✅ Çözülen açık sorular
- **Kapsam kararı:** genel-ayarlar = organizasyon havuzu, servis-ayarlari = servis-bazlı.
- **ActionDto kopya ↔ canlı referans:** bağımsız kopya (FK yok).
- **`SetStyle`:** Style varlığı seçmez; tekil nitelik (fontSize/titleColor) değiştirir.
- **Status renk:** `icon`+`definition` = `styleId`.`fontColor`.
- **Dil seti:** `languageCode` sabit set (`tr`/`en`/`de`); yeni dil = kayıt (şema değişmez).
- **Değer Atama expression:** `FromCalculation`.
