## 🔧 Değişenler / kararlar
- **Image Area Selector (`imageAreaSelector`) alan tipi KALDIRILDI.** `dataSource` alan adının **çift anlamı** (Combobox/Radiobutton
  dinamik kaynak ↔ görsel statik nokta listesi) bu tip kaldırılarak giderildi. **Alan tipi sayısı 19 → 18.**
  - **Dosyalar:** `service-settings/properties.md` (§1 taksonomi · **§3.19 kaldırıldı** · §2.4 karar notu) ·
    `models/service-settings/property.md` (§2 tablo satırı + Notlar) · `models/enums/property-type.md` (değer + not) ·
    `service-settings/index.md` · `models/enums/index.md` (sayaç 19→18).
- **`dataSource` tek anlamlı + `propertyItem` devam (KARAR).** `dataSource*` artık yalnız seçim alanı (Combobox/Radiobutton)
  **dinamik seçenek kaynağı**; **datasource için ayrı tablo ayrıştırılmaz** — statik seçenekler **`propertyItems`** (`PropertyItem`)
  ile **aynen** devam eder (dinamik = iş kuralı `fillDataSource`).
- **Grup onayı (`groupApproval`) özelliği KALDIRILDI (ilk faz).** Grup "hepsi onaylar" eşiği ilk fazda gereksiz. Kullanıcı Grubu
  adımı kalır; **üyelerden biri** aksiyon alınca ilerler. **Silinen:** adım alanı `groupApproval` (`service-settings/process-step.md`
  §3.16 · `models/service-settings/process-step.md` §3.11) · `UserGroup.groupApprovalRequired` (`models/organization-settings/user-group.md`) ·
  **`UserGroupApprovedUser` modeli tümden** (`models/processInstances/user-group-approved-user.md` **dosya silindi** + `index.md` satırı +
  `instance-awaiting-user.md` ilişki/not + `models/index.md` ERD/FK/açıklama + `enums/process-step-user-group-type.md` +
  `enums/process-step-type.md` + `organization-settings/index.md`). Runtime model sayısı **6 → 5**; compare ×2 güncellendi.
- **Süreç başlatma kısıtı (`userGroupId`) davranışı işlendi.** Model tanımı doğru teyit edildi; davranış eklendi: manuel
  başlatmada **görünürlük = tetikleme yetkisi** (grup dışı görmez), **webhook/Customer API** kısıttan etkilenmez (`ApiKey` ile
  kimlik). **Dosyalar:** `service-settings/process-step.md` §3.1 + `models/service-settings/process-step.md` §3.14.
