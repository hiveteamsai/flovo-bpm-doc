## 🔧 Değişenler / kararlar
- **KARAR — Veri modeli = koleksiyon-tabanlı (Tier 1) + ortak değer dili:** Adımlar arası veri, `InstanceValue.data` ile
  **aynı değer-modeli** (`propertyValuesTemplates` + `LabeledValue`) taşıyan bir **değer koleksiyonu** olarak aksiyonla **açıkça**
  akar (token-tabanlı değil). **`changeList`** = **obje-map** `{ Property.code: value }` → forma **doğrudan JSONB merge**
  (`data = data || changeList`), yalnız **yazılabilir** alanlar (`text`/`live`/`savePropertyToDb=false` hariç). **`parameters`** =
  aynı değer şekli, **serbest anahtar** (form alanını besliyorsa konvansiyon hedef `Property.code`), forma yazılmaz, `mergeParameter`
  ile birikir. **Bütünsel taşıma:** alan değeri model/dizi ise alt-alan değişse bile **tüm değer komple** taşınır (kısmi patch yok).
  **Kapsam sınırı:** karar **temsili** çözer; n8n item-dizisi **otomatik fan-out/iterasyon** (loop/join) hâlâ açık. İşlendiği yerler:
  `flovo-bpm-engine.md` §3 (+ durum satırı) · `process-step-action.md` §2 (tablo + jsonc + yeni **§2.2 Değer modeli**) ·
  `models/processInstances/instance-value.md` (ortak-dil notu) · `models/service-settings/process-step-action.md` (açık-nokta) ·
  `research/compare/new-vs-n8n.md` (veri-akışı satırı + zayıflık notu) · `todo.md` (Tier 1 + Tier 3).
- **KARAR — Genişletilebilirlik = sabit / kapalı set (Tier 0):** Adım / aksiyon / alan tipleri **önceden tanımlı, kapalı bir
  settir**; plugin/SDK ile **üçüncü-taraf yeni tip eklenemez**. Tüm tiplerin ayarları **ve** BPM motorundaki yürütme davranışı
  **Flovo tarafından** geliştirilir/bakılır; yeni ihtiyaç = **çekirdek motor geliştirmesi** (kataloğa/enum'a yeni değer),
  harici bir genişletme noktası **yok**. İşlendiği yerler: `process-step.md` §1 (karar notu) + §4 log · `process-step-action.md`
  §3 + §7 log · `properties.md` §3 + §4 log · `models/enums/process-step-type.md` Notlar · `models/service-settings/process-step.md`
  (JSONB gerekçesi + açık-nokta listesi) · `research/compare/new-vs-n8n.md` §8 (n8n açık-node ekosistemine karşı bilinçli ödünleşme).
