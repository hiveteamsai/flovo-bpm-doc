- **İş kuralı (BusinessRule) model ailesi — iskelet kuruldu:** eski `WorkRule` DTO ailesi **yeni isimlerle**, parçalanmış olarak

  `PropertyAttributeType` (`minDate`/`maxDate`/`helperText`/`sideText`/`addNewEnabled` — **kontrol tipi `PropertyType`'tan ayrı**).

## 🔧 Değişenler / kararlar
- **İş kuralı fazı — yön kararları (v0.34):** **çalışma yeri = tam frontend** (kurallar servise gömülü gelir, her client kendi
  motorunu yürütür) · ifade motoru = **standart + sandbox** (dil çok-client portlanabilir olmalı; eski fonksiyon kataloğu üstte) ·
  aksiyon konfigi = **yapısal JSONB** (`BusinessRule.configuration`; string-içinde-JSON değil) · düzeltilecek sınırlamalar =
  **tetikleme kapsamı** (aksiyon/ifade alanları da tetikler) + **kural önceliği** (`priority`). İşlendi: `models/service-settings/business-rule.md`
  (`configuration` + `priority` alanları · aksiyon→DTO şema haritası · tam-frontend/JSONB/tetikleme/priority KARAR notları).
- **İsim/tutarlılık dönüşümleri (`new-vs-current-names.md` §8):** `SetViewForFields`→`setViewForProperties` · `AssignValueToField`→
  `assignValueToProperty` · `assignValueToPropertyField`→`assignValueToPropertyAttribute` · `Function`→`httpRequest` ·
  `FieldValue`/`FormValue`→`propertyValue` · `ModalList`→`formList` · `field`→`property`. **Kaldırıldı:** `FromEba` · `changeViewProfile` ·
  DataGrid `childField` · dil-başına `...En` kolonları (**iki ayrı çözüm:** `fixedValueEn`→`fixedValue.translationCode`/Translation §10; **`fromCalculationValueEn`→ çok-dilli ifade listesi** `expression` default + `localizedExpressions [{languageCode, expression}]` eksik dilde default — translationCode DEĞİL, expression dinamik).
- **Ertelendi (açık → todo Tier 2 "İş kuralı — açık detaylar"):** `organizationData` kaynak kapsamı (`OrganizationDataSourceType`/
  `OrganizationParameter`/`SubTextType` + masraf-spesifik tipler) · `search` değer kaynağı · `setStyle` `style` obje şeması ·
  `showMessage` "bir kez göster" · döngü/derinlik limiti + hata görünürlüğü · `ValueTypeOfList`/`IsActiveKkegAttachment` (masraf-niş).

## 🩹 Düzeltmeler
- **SOLID — discriminated union (Orta seviye):** şişman union DTO'ları (`AssignValue` · `BusinessRuleConditionCompareValue` ·
  `FillDataSource`) **"ayrımlayıcı + yalnız o tipe ait payload (oneOf)"** olarak yeniden kuruldu — **ISP** (her tip kendi alanları) +
  **OCP** (yeni tip mevcut payload'ları bozmaz). `AssignValue`: sabit `fixedValueEn`→`fixedValue.translationCode`; dinamik `fromCalculationValueEn` → **çok-dilli ifade listesi** (`expression` default + `localizedExpressions`, eksik dilde default; translationCode DEĞİL); düz-opsiyonel
  alanlar (`sourcePropertyId`/`fromCalculation`/…) tip-payload'larına gruplandı. `FillDataSource.companyId` → `FillDataSourceOrganization`
  (**SRP**). `business-rule-condition.md` compare-value payload yapısına hizalandı; bağımlı JSON örnekleri güncellendi. Konvansiyon
  `dto/business-rule/index.md`'ye işlendi.
- **Klasör ağacı düzenlendi (okunabilirlik):** `dto/business-rule/` altındaki 15 dosya 3 alt gruba ayrıldı — **`actions/`** (7 aksiyon
  konfigi) · **`shared/`** (AssignValue · PropertyAppearance · condition-compare-value) · **`data-source/`** (dataset + fillDataSource
  kaynakları); her alt klasöre `index.md` + ana index ağaç görünümüne çevrildi. Tüm iç/dış linkler yeniden hesaplandı (916 link, 0 kırık).

- **İsim tutarlılığı (Form List):** eski-`ModalList` kalıntısı alan adları `formList`'e hizalandı — `withModal`→`withFormList` ·
  `modalPropertyId`→`formListPropertyId` · `withModalCondition`→`formListRowCondition` (`apply-validation` + `set-style`; new-vs-current-names §8).
