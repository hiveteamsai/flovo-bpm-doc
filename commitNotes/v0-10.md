## 🆕 Eklenenler
- **Property value depolama araştırması eklendi:** `research/property-value-storage/` klasörü oluşturuldu; kullanıcının
  hazırladığı `form-deger-saklama-sunum.html` (CQRS Projection · Outbox · Postgres/JSONB tabanlı form/property değeri saklama
  mimarisi) proje köküden buraya taşındı. Klasöre hiyerarşik `index.md` yazıldı (HTML'in özeti + 🟡 **değerlendirme bekliyor**
  notu + ilgili tasarım dokümanlarına link). `research/index.md`'ye alt klasör satırı eklendi. `todo.md`'deki **"Property value
  depolama modeli"** açık sorusuna 📎 araştırma-girdisi işaretçisi eklendi. **Not:** araştırma henüz tasarıma dahil edilmedi;
  değerlendirilip karara bağlanınca `form-value-scenarios.md` / `models/` PropertyValue'a işlenecek.
- **`form_attr` uygunluk değerlendirmesi başlatıldı:** `research/property-value-storage/form_attr_questions.md` (🟡 AÇIK) —
  `form_attr` projeksiyon tablosunun projeye uygunluğunu değerlendiren **soru-cevap** çalışma dosyası; kullanıcının soruları +
  cevapları biriktirilir, sonda toplu karar verilir. Klasör `index.md`'sine eklendi. **S1–S13** işlendi (detay-okuma · yazma/sync ·
  yansıma FlowInfo/UserInfo/ParentProperty · A/B/A′ karar kuralı · şema evrimi · combobox isim-sıra · list-item pivot · display/
  translationCode kolonları · 150+ prop büyük JSONB · tek-tablo↔1-1 yerleşim · code vs id · code-rename/immutable · **5M/200M ölçekli
  tam senaryo taraması + risk/geliştirme listesi**).
- **`form-value-scenarios.md` taşındı:** `bpmEngine/` kökünden → `bpmEngine/research/property-value-storage/` (depolama
  araştırmasıyla eş-konumlu). Tüm linkler güncellendi (bpmEngine/index.md'den doğrudan-dosya satırı çıkarıldı → research özetine
  eklendi; klasör index.md Dosyalar tablosuna eklendi; instance.md + iç linkler `../../` düzeltildi). Link denetimi temiz.
- **`form_attr_scenerios_rating.md` oluşturuldu:** `research/property-value-storage/` altında — her senaryonun (`form-value-scenarios.md`
  §1–§11) `form_attr`'a karşı **ölçekli** (5M+ instance · 150+ prop · 40+ form_attr → ~200M satır) **detaylı puanlaması**
  (🟢/🟡/🔴/⚫ ölçeği + bölüm-bölüm gerekçe) + **9 performans riski (P1–P9)** + **14 ek geliştirme (D1–D14)** + geliştirme→senaryo
  önkoşul haritası + **faz sırası** (Faz 0 çekirdek → Faz 3 koşullu). Klasör index.md'sine eklendi.

- **`form-value-scenarios.md` konumu değişti:** `bpmEngine/` kökü → `bpmEngine/research/property-value-storage/` (depolama
  araştırmasıyla eş-konumlu). `bpmEngine/index.md` doğrudan-dosya tablosundan çıkarıldı, research özetine eklendi.
- **Değerlendirmeden çıkan tasarım-çıkarımları (henüz karara bağlanmadı — `form_attr_scenerios_rating.md`'de):** `Property.projectionLevel`

  `form_value.data` **code-keyed** · churny alan asla JSONB içinde değil. Karara bağlanınca `property.md` / `models/`'e işlenecek.
