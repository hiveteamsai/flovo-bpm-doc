# Eski Flovo — Organizasyon Ayarları — Analiz İndeksi

> **Amaç:** Eski Flovo'nun **Organizasyon Ayarları** modülünü (`Ayarlar > Organizasyon Ayarları`) analiz eden DTO
> dokümanları — BPM motorunun üzerinde çalıştığı organizasyonel altyapı (şirketler, kullanıcılar, hiyerarşiler, takvimler vb.).

## Dökümanlar
| Döküman | Özet |
|---|---|
| [`organizations.md`](./organizations.md) | Modül genel bakışı — organizasyonel altyapının BPM ile ilişkisi + kapsam notu. |
| [`companies.md`](./companies.md) | Şirketler — hukuki/mali tüzel kişilikler; çok-şirketli yapının temeli. |
| [`users.md`](./users.md) | Kullanıcılar — kişiler; departman/ünvan/yönetici/masraf yeri bağları, onay merci. |
| [`user-groups.md`](./user-groups.md) | Kullanıcı grupları — toplu onay, bildirim ve aksiyon yetkilendirmesi. |
| [`departments.md`](./departments.md) | Departmanlar — hiyerarşik birim yapısı; departman yöneticisi atamaları. |
| [`titles.md`](./titles.md) | Ünvanlar (kodda `Profession`) — görev/meslek tanımları; "ünvana göre yönetici". |
| [`worker-levels.md`](./worker-levels.md) | Çalışan seviyeleri — personel kademe/seviye tanımları. |
| [`expense-center.md`](./expense-center.md) | Masraf merkezi (Cost Center) — maliyet takibi yapılan muhasebesel birimler. |
| [`credit-cards.md`](./credit-cards.md) | Kredi kartları — harcama süreçlerinde kullanılan kurumsal kartlar. |
| [`additional-qualifications.md`](./additional-qualifications.md) | Ek nitelikler — organizasyon varlıklarına eklenen özel/dinamik alanlar. |
| [`positions.md`](./positions.md) | Pozisyonlar ve kadrolar — organizasyon şemasındaki fiili görev yerleri + personel slotları. |
| [`working-schedules.md`](./working-schedules.md) | Çalışma takvimleri — haftalık mesai; Timer/zaman aşımı hesaplarının temeli. |
| [`vacation-days.md`](./vacation-days.md) | Tatil günleri — resmi/çalışılmayan günler; iş günü/süre hesabında dikkate alınır. |
| [`scheduler-jobs.md`](./scheduler-jobs.md) | Zamanlanmış görevler — cron ile periyodik arka plan işleri (+ log). |
| [`process-transfer.md`](./process-transfer.md) | Süreç transferi — bekleyen görevlerin başka kullanıcıya devri. |
